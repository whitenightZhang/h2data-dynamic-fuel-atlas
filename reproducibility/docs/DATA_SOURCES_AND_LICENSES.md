# Data sources and sharing

Code and author-generated processed research outputs follow the repository's existing MIT license. The original global meteorological, land-cover, runoff and other third-party products are not redistributed here. Third-party basemap shapefiles and rendered document/figure assets are also excluded from this distribution. Their providers' terms continue to govern their use. Source citations are retained in data_sources.bib and the processing notebooks.

Included source CSVs are processed numerical inputs and outputs for the current manuscript, not a replacement for the full external raw-data collections. Table S6 utilization values are included as their previously archived group summaries. The main assessment uses 2023 hourly weather; the representative sensitivity spans 2021–2023; mean annual runoff covers 2021–2025 as described in the paper methods.

The GitHub web atlas uses its pre-existing world-110m.json asset and public third-party web libraries; their original upstream terms remain applicable. The numerical figure-data package omits separate third-party geospatial layers.
